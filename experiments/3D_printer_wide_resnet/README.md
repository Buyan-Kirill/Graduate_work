# 3D Printer Wide ResNet

Ранние эксперименты с FastFlow/backbone на датасете 3D-принтера. Здесь проверялся Wide ResNet как extractor/backbone.

## Содержимое

- `try_1` - `try_3` - отдельные попытки.
- `final_metrics.txt` - итоговые метрики для завершенных запусков.
- `middle_logs/` - чекпоинты, метрики и визуализации.

Используется как ранний baseline перед переходом к ResNet-18 и затем SuperSimpleNet.
