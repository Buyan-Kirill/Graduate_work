Цель запуска: Бейзлайн для датасета с принтера на FastFlow с backbone ResNet18
Ключевые настройки: Модель FastFlow с backbone ResNet18, 10 flow steps, 8 эпох, learning rate 1e-5, weight decay 5e-5, eta_min 1e-6, batch size 32. Размер тренировочного датасета - 1000 изображений, валидационного 160, тестового: 37 нормальных и 46 аномалий.
Комментарий: Этот запуск предназначен для получения базовых результатов на новом датасете с принтера, используя FastFlow с ResNet18 в качестве backbone. Результаты этого запуска будут служить отправной точкой для дальнейших экспериментов и оптимизаций.
