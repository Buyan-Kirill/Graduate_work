# 3D Printer ResNet-18

Ранние эксперименты на датасете 3D-принтера с ResNet-18 как extractor/backbone.

## Содержимое

- `try_1` - `try_3` - отдельные попытки запуска.
- `final_metrics.txt` - итоговые метрики, если файл сохранен для конкретной попытки.
- `middle_logs/` - промежуточные логи, чекпоинты и визуализации, если они не исключены из Git.

Эта серия нужна как ранний baseline перед переходом к SuperSimpleNet.
