# 3D Printer SuperSimpleNet

Первые базовые запуски SuperSimpleNet на датасете 3D-принтера, до fine-tuning.

## Содержимое

- `try_1`, `try_2` - отдельные запуски.
- `final_metrics.txt` - итоговые `Train_Loss` и `Validation_Loss`.
- `middle_logs/` - чекпоинты, графики и визуализации.
- `anomaly_visualization/`, `normal_validation_visualization/` - примеры результата на аномальных и нормальных изображениях.

Эта папка нужна как baseline перед `3D_printer_supersimplenet_head_finetune`.
