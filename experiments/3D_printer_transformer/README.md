# 3D Printer Transformer

Ранняя проверка transformer-подхода на датасете 3D-принтера.

## Содержимое

- `try_1` - `try_4` - отдельные попытки.
- `final_metrics.txt` - итоговые `Train_Loss`, `Val_Loss`, `Best_Val_Loss`.
- `middle_logs/` - промежуточные метрики и визуализации.

Папка оставлена для истории ранних сравнений с CNN/FastFlow и дальнейшим переходом к SuperSimpleNet.
